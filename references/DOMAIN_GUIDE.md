# 教案质量审查领域指南

## 业务问题

教案往往结构完整但目标、活动、评价不一致，教研审批只能做格式检查，难发现可执行性问题。

## 产品解决方案

对既有教案做目标一致性、认知负荷、活动可行性、评价证据、时间分布和差异化支持审查。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `lesson_plan` | 待审教案 | 是 | 完整教案正文 |
| `curriculum_standards` | 课程标准或目标依据 | 是 | 来源需可追溯 |
| `grade_and_subject` | 年级与学科 | 是 | 教材版本和适用地区可选 |
| `student_profile` | 学情摘要 | 否 | 脱敏且只保留与教案审查有关的字段 |
| `lesson_duration` | 课时长度 | 是 | 分钟或标准课时 |
| `resources` | 可用资源 | 是 | 场地、设备、材料和班型限制 |
| `review_focus` | 审查重点 | 否 | 例如目标对齐、认知负荷或差异化 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

不能替代学科专家终审；对教材版本、课程标准和敏感内容必须提供依据或标为待确认。
